#Diferencia entre protocologo IMAP y pop3:
El protocol IMAP sincronitza els correus directament al servidor, permetent consultar i gestionar la mateixa bústia des de diversos dispositius en temps real. En canvi, POP3 descarrega els missatges a un únic dispositiu local i, per defecte, els esborra del servidor, de manera que no es mantenen sincronitzats entre diferents equips.
